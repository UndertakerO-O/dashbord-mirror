# Dashboard

Dashboard personnalisable développé avec NestJS et Vue.js.

## Structure du projet

```text
.
├── backend/              # API NestJS
├── frontend/             # Interface Vue.js
├── docs/                 # Documentation et benchmark
├── decision-matrix.md    # Matrice de décision initiale
├── docker-compose.yml    # À ajouter à l’étape suivante
└── README.md
```

## Choix techniques

- Backend : NestJS et Node.js
- Frontend : Vue.js 3 et Vite
- Base de données : PostgreSQL
- ORM : Prisma
- Styles : Bootstrap CSS
- Conteneurisation : Docker Compose

Le benchmark complet est disponible dans [docs/benchmark.md](docs/benchmark.md).

## État actuel

Les choix technologiques et la structure initiale sont documentés. La configuration Docker, les dépendances et le premier endpoint seront ajoutés dans les prochaines étapes.
